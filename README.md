## Project Summary

SUB-CHECK is a server-side behavioral anti-cheat platform designed for multiplayer and competitive games. Instead of relying on invasive kernel-level software, SUB-CHECK analyzes player input behavior and produces a risk score that can be used for manual review, additional verification, or other enforcement mechanisms.
