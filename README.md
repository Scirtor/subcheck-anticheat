## Project Summary

**SUB-CHECK** is a server-side behavioral anti-cheat platform designed for competitive multiplayer games. Instead of relying on invasive kernel-level software (Ring 0) that compromises privacy and restricts platform compatibility, SUB-CHECK analyzes player input behavior (kinematics, view angles, micro-tremor biometrics, and reaction latency) on the server side. It produces a normalized cheat probability risk score that enables real-time risk-driven enforcement, quarantine matchmaking, and targeted manual review without penalizing legitimate players.
